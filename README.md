# Space Runner

Standalone static edition of Space Runner, prepared for GitHub Pages.

## Run locally

Serve this directory through a local HTTP server, then open `index.html` through that server. ES modules and audio loading are not expected to work reliably through a direct `file://` URL.

## Controls

- Move: arrow keys
- Shoot / skip intro: Space
- Pause: P or the pause button in the canvas
- Leave expanded mode: Back or Escape

The final score is displayed locally at the end of a run. This standalone edition does not use accounts, an API, or an online leaderboard.
